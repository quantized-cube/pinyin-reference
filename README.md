# Pinyin Atlas

日本語で使う、普通話のピンイン・IPA・発音リファレンス。TypeScript 7.0.2 / strict モードで実装しています。

[公開アプリ](https://pinyin-reference.pages.dev/) · [GitHubリポジトリ](https://github.com/quantized-cube/pinyin-reference)

## 起動

Windows で `start.cmd` をダブルクリックすると、ローカルサーバーが起動して既定のブラウザが開きます。Node.js 24 を推奨します（対応範囲：20.19以降の20系、22.13以降の22系、24以降）。インストール済みの Node.js 24.22.1 で確認しました。初回は開発用パッケージを自動インストールし、起動のたびにTypeScriptをビルドします。初回インストールにはネット接続が必要です。

PowerShell から起動する場合は、プロジェクトのフォルダーで実行します：

```powershell
npm ci    # 初回のみ
npm start
```

ブラウザで <http://127.0.0.1:4173> を開きます。停止するときはサーバーのウィンドウで Ctrl+C。4173 番が使用中の場合は既存サーバーを利用するか、`$env:PORT = '4174'` を指定してから `npm start` で起動します。

`dist/index.html` の直接ダブルクリック（file://）では、JavaScriptモジュールと例語取得が制限されるため、上記のローカルサーバーを使ってください。

## Cloudflare Pages で公開

ビルド後の `dist/` はHTML・CSS・JavaScript・JSON・音声ファイルからなる静的サイトです。Cloudflare Pagesで公開でき、サーバーの常駐やアプリ用APIキーは不要です。聞き比べの15組と軽声の高さの4例には、同梱の話者録音を使います。音節詳細の第1〜4声の単独音も同梱の録音を使います。音節詳細の半三声・3声＋3声も7例は録音を使います。それ以外の半三声・3声＋3声と軽声の例語には、閲覧者の端末・ブラウザが提供する普通話の読み上げ音声を使います。

GitHubにプロジェクトを保存し、Cloudflare PagesのGit連携でリポジトリを選択します。公開・非公開のどちらのリポジトリも対応しています。

## できること

- 21声母＋声母なしの行、38列、413音節のマトリクス。`i` の3種類を1列にまとめ、見出しに `[i / ɹ̩ / ɻ̩]` を併記します。各音節のIPA・詳細では発音の区別を維持します。存在する収録音節だけを選択できます。
- マトリクスの声母を、声母なし・唇音・舌尖音（歯茎音）・舌根音（軟口蓋音）・舌面音（歯茎硬口蓋音）・そり舌音（舌尖後音）・舌歯音（歯茎音）の見出しで区切ります。声母一覧と詳細も同じ名称を使います。
- 韻母一覧とマトリクスは、単韻母・複合韻母・鼻韻母（-n、-ng）・補足の音節に分類します。`ê`・`er` は単韻母に含め、韻母一覧の `i（yi・mi系）`・`i（zi系）`・`i（zhi系）` は別カードで隣り合わせに配置します。補足のカードは `yo` と表示し、分析上の韻母が `io` であることを説明します。
- 全音節のピンイン・IPA、声母と韻母への分解、表記上の変化。
- 声母一覧、韻母一覧、表記規則と声調ガイド。
- 「児化」タブ：`diǎn → diǎnr` の例、韻母ごとの代表的な変化、綴りと発音の違い、独立した `er` との違いを説明。韻母一覧と `ian・üan・er` の詳細からも開けます。9組の児化前・児化後の録音を聞き比べられます。児化音の検索は未対応です。
- 韻母一覧と母音図に「母音・子音と、声母・韻母はどう違う？」を掲載。短い要点と折りたたみ説明で、`ban` の分解、`an / ang` の鼻子音、`uang` の介音・主母音・韻尾を示します。
- 声母一覧と音節詳細に、両唇音・唇歯音などの調音位置、破裂音・摩擦音などの調音方法、無気／有気、無声／有声のラベルと用語説明。無気・有気の6ペアを例音節で比較できます。
- 検索対象を「ピンイン・用語」と「IPA」で切り替えます。通常の `pa` はピンインだけを照合し、IPAが `[pa]` の `ba` は混ぜません。IPAモードでは `pa` や `[pa]` と入力できます。ピンインモードは `nǚ`、`nv3`、`nu:3`、`ma0`、`ma5` に対応。
- 「舌根音」「軟口蓋音」「舌歯音」「舌尖前音」「舌尖中音」「舌面後音」「平舌音」「双唇音」など、教材名・音声学名・別名による検索（マトリクス・声母一覧）。「唇音」「無気音」「有声音」「鼻音」などの検索も使えます。
- 韻母グループ、声母、周辺的な音節による絞り込みとIPA併記。IPAはPC幅（800px超）で初期ON、スマートフォン幅では初期OFF。変更した設定は `localStorage` に保存し、次回以降は画面幅より優先します。
- 第1〜4声・軽声の綴りと調形。単独音と一部の例語は録音で再生し、それ以外の例語にはTTSを使います。停止に加え、TTSでは音声と速度を選べます。
- 第3声の「全三声 / 半三声 / 3声＋3声の変調」を切り替え、辞書の読みと発音形の目安を区別。全三声は単独音の録音を再生し、例字を参考表示します。半三声・変調は21音節・41例の文脈例語を収録し、うち7例は録音で再生します。
- 「聞き比べ」タブ：鼻韻母の比較（-n / -ng）6組（uan / uang は关 guān・光 guāng、uen / ueng は温 wēn・翁 wēng）、無気・有気6組、「s・sh・x／z・zh・j／c・ch・q の比較」3組（si / shi / xi、zi / zhi / ji、ci / chi / qi）の計15プリセット。最後の3組では、舌の位置による声母の違いと、続く i の発音を聞き比べます。音節の組み合わせは固定で、すべて第1声です。プリセットを選んで、個別再生と順番の再生を行えます。
- 「母音図」タブ：中国語の代表的な母音位置を示す模式図。母音から詳細へ移動でき、日本語のあいうえおの代表的な位置を初期表示で重ね、チェックを外すと非表示にできます。
- 検索への `/` キー、マトリクス上の矢印キー、Home / End。Enter / Space で音節を選択。検索欄のEnterは、マトリクスでは絞り込み後の検索結果、声母・韻母一覧では最初に表示されているカードの例音節を選びます。
- スマートフォン幅のレイアウト。選択音節・声調・第3声の発音形をURLのハッシュで再現。

`xuan` は `x + üan`、`jun` は `j + ün`、`dun` は `d + uen`。`iou → iu`、`uei → ui`、`uen → un`、`ü → u`、声母なしの y / w 規則を説明します。

声母の分類は本アプリのIPA表記に合わせ、[ワシントン大学の子音表](https://courses.washington.edu/chin342/ipa/consonants.html)などで照合しています。有気／無気の対比は破裂音・破擦音に付けます。`m / n / l / r` は有声音として表示し、`r` は接近音 `[ɻ]` を採用（摩擦音 `[ʐ]` とする分析も注記）。教材の名称は [BitExの音節表](https://bitex-cn.com/?a=fourtone&m=dic)、別名は [華中師範大学の普通話解説](https://music.ccnu.edu.cn/info/1661/42641.htm)などで照合しています。「舌尖音」はこの表では d/t/n/l（舌尖中音）の名称として使い、舌尖前・中・後をまとめる広い用法もあることをガイドに説明しています。用語説明は本アプリ用に作成しています。

## 聞き比べと母音図

聞き比べでは、15組の固定プリセットから選び、同じ話者による第1声の音節の録音を再生します。音節・音数・声調の自由設定はありません。鼻韻母の比較例は、`an ↔ ang` が `ān ↔ āng`、`en ↔ eng` が `bēn ↔ bēng`、`ian ↔ iang` が `xiān ↔ xiāng`、`in ↔ ing` が `yīn ↔ yīng`、`uan ↔ uang` が `guān ↔ guāng`、`uen ↔ ueng` が `wēn ↔ wēng` の6組です。声母や韻母だけを切り出した録音ではありません。録音は27音節を収録し、例字データを読み込めない場合も再生できます。軽声の音声は文脈が必要なため、単語全体で確認します。「表記と声調」の高さの目安では話者録音を、詳細欄の例語ではTTSを再生します。

3音比較は `sī / shī / xī`（思・诗・西）、`zī / zhī / jī`（资・知・鸡）、`cī / chī / qī`（疵・吃・七）を第1声で比較します。s / sh / x、z / zh / j、c / ch / q の声母に加え、後続する i も異なる音なので、カードには声母と韻母のIPAをそれぞれ表示します。声母だけの分離録音ではありません。PCの広い画面では3列、狭い画面では縦に並べます。

2音は A → B → A → B、3音は A → B → C → A → B → C の順で、それぞれ2回ずつ再生します。各音の間に約0.4秒を置きます。停止・新しい再生・プリセットや音声設定の変更・音節詳細の操作・タブ移動で残りの再生も取り消します。録音は原速で再生し、詳細欄のTTS音声・速度設定は適用しません。表示する単独例字は音節詳細と同じ一覧を参照し、読みを保存済みCC-CEDICTの字見出しで照合しています。録音の有無は例字一覧と別に管理し、対応する録音がない音節や声調では再生を無効にします。

母音図はIPAの分類を参考にした模式図です。中国語の i / ü / u / e / o / ê / a と、日本語の代表的な位置を表示します。日本語の重ね表示は初期ONで、同じページ内のタブ移動でも切り替え状態を保ちます。i / ü と e / o の隣接は唇の丸めの違いを示します。同じ舌位置の非円唇母音と円唇母音は、IPA母音図では左・右の順に並べて表します。図上の距離は実測値ではありません。日本語「う」は [ɯ̟] と略記し、唇の圧縮や話者差を注記します。舌先の i は [ɹ̩ / ɻ̩] と表し、音節の中心になる接近音として扱います。母音四辺形の外の補足欄で説明します。zī・zhī の詳細へ移動できます。er のそり舌性、二重母音の移動は図の対象外です。

## 児化

「児化」タブは語末の -r による韻母の変化を学ぶための解説です。`diǎn [tjɛn] → diǎnr [tjɐ˞]` は声調を省いた広い表記の一例とし、ian の児化を `[jəɚ]` 系で表す分析も注記します。韻尾の脱落、母音の音色・鼻音の響きの変化をまとめ、発音で n・ng が消えても綴りには残ることを説明します。すべての語の児化を自動生成するものではありません。音節詳細では引き続き基本音節を表示・再生します。

韻母ごとの表には、児化前後のIPAと声調記号付きの綴りの例を載せています。共通する変化ごとに区切り、各韻母の対応を一行ずつ表示します。児化前のIPAは韻母一覧と共通で、唇音後の o は音節表示に合わせて `[wo]` としています。児化後は複数の資料を参考にした広い表記の例で、ian・üan・ie・üe には別の分析も併記しています。鼻音の響きやrの響きを表す記号も説明します。独立した er と、感動詞の ê・io は表に含めません。

参考は[湖南信息職業技術学院に掲載された普通話水平測試大綱の解説](https://www.hniu.cn/jxxy/info/1126/1327.htm)と[Lee（2005）の北京語の児化韻の研究](https://www.isca-archive.org/interspeech_2005/lee05d_interspeech.pdf)です。母音図の舌先の i の説明は[PHOIBLEの表記方針](https://phoible.github.io/conventions/#apical-vowels)と[Lee-Kim（2014）](https://doi.org/10.1017/S0025100314000267)を参照しています。

児化の例字と分類は[端木三（2021）の表29](https://websites.umich.edu/~duanmu/2021syllable_count.pdf#page=27)も参照しています。ie・üe と舌先の i の説明は[西安理工大学の児化解説](https://rwxy.xaut.edu.cn/info/1080/1812.htm)とも照合しています。介音や二重母音は本アプリの表記に合わせているため、各資料のIPAをそのまま転載した表ではありません。

「韻母ごとの主な変化」の該当行で、馅／馅儿・玩／玩儿・哪／哪儿・画／画儿・带／带儿・兜／兜儿・个／个儿・座／座儿・空／空儿の9組を同じ声調で比較できます。表の例語を録音に合わせ、同じ行のボタンで児化前・児化後を個別に、または前→後の順に再生します。録音のない行には「録音未収録」と表示します。前後の話者は異なります。どちらも一音節全体の録音を元の速度で再生し、音節詳細の選択や声調は変えません。タブ移動や別の録音の再生、停止ボタンで残りの再生を取り消します。

児化前は既存の単独音の録音を共用します。児化後は The Shtooka Project の録音をWikimedia CommonsとThe Yojik Websiteから取得しました。出典とライセンスは [credits.html](public/audio/erhua/credits.html)、取得日・変換内容・SHA-256は [credits.json](public/audio/erhua/credits.json) に記録しています。聴取による発音の自然さの確認は未実施です。

## 第3声・半三声の比較

`lao3` を検索して第3声を選び、「半三声・変調を詳しく見る」を開いて切り替えます。初期表示は折りたたみ、単独の発音を中心に表示します。「表記と声調」の詳細ガイドも折りたたみます。半三声・変調を指定したURLを開くと該当欄が開きます。

| 発音形 | 代表的な調形 | 比較例（下線の対象は最初の音節） |
|---|---|---|
| 全三声 | 214 / [˨˩˦] | 老 lǎo：丁寧な単独形の目安 |
| 半三声 | 21 / [˨˩] | 老师 lǎoshī：後半を上げない低い形 |
| 3声＋3声の変調 | 35相当 / [˧˥] | 老板 lǎobǎn：同じまとまりの前の第3声が上昇形になる |

「表記と声調」の第3声ガイドからも、この3例を選べます。すべて録音で再生しますが、話者はそれぞれ異なります。

辞書の読みはすべて第3声のままです。半三声・変調を選んでもピンインの `ǎ` は変えず、IPAと調形図、対象音の発音の目安を切り替えます。比較例は発音形ごとに手動で選び、CC-CEDICTに読みが存在することを生成時に検証しています。すべて音声を聴取検証したデータではありません。

全三声は丁寧な単独発音などでの代表形で、自然な発話では語末でも上がらないことがあります。半三声の比較例には第1・2・4声の前を採用しています。軽声の前は語ごとの性質も関係し、第3声が3つ以上続く場合も意味・韻律上の区切りが関係するため、自動判定は行いません。

対応する比較例がない場合は再生を無効にし、`lǎo` の同じ発音形の比較例へ移れます。全三声は、採用済みの単独音の録音を再生します。異なる発音形や文脈の例語を代わりに再生しません。

調値・IPAは学習用の代表値で、再生音声の測定値ではありません。全三声には単独音の録音を使います。半三声・3声＋3声の7例は例語全体の録音で、それ以外の半三声・変調の例語はブラウザTTSで再生します。TTSでは調形を直接指定できないため、図どおりの発音になるとは限りません。

## 例字・例語の選び方

データは `isolatedExamples`（単独例字）、`contextualExamples`（一般の文脈例語）、`thirdToneExamples`（半三声・変調用の手選定例語）に分けています。詳細の1・2・4声は参考の単独例字を優先表示し、ない場合は参考の例語を表示します。再生するのは対象音節の単独録音です。全三声の参考表示には単独例字を使い、軽声は文脈例語全体を再生します。聞き比べは単独例字を表示しますが、音声には同梱の音節録音を使います。全三声用の例字を別に重複保存しません。

単独例字の採用順は、辞書で読みを確認した手選定 → 身近な字のリストにある異読のない字 → 未収録です。このリストは編集上の選定で、コーパスの頻度順位ではありません。リストにない字を漢字の文字コード順で自動採用しません。`yǎn=眼`、`yǐn=引`、`yǐng=影` を明示し、`lǐ=理` なども音節詳細に採用しています。聞き比べの第1声例字は、音節詳細と同じ一覧を参照します。

自動選定では多音字や異体字・古語・方言等の注記を除外します。通常の語義と別の読みの注記が併記された「剖 pōu」などは、理由を添えた手選定で採用できます。「给」は gěi と jǐ の読みがあるため自動選定から外れますが、単独例字として `gěi=给` を明示的に採用しています。手選定は単字・1〜4声・辞書の読みとの一致を必須とし、不一致は生成エラーにします。辞書照合は実端末のTTSの読みを保証する検証ではありません。

2026-10-21のデータは単独例字513件（うち第3声252件）、一般の文脈例語1,440件、半三声・変調41例です。「甩」に加え、未収録箇所の調査で選んだ第3声191件、第1・2・4声100件を、保存辞書で読みと一般的な意味を確認して手選定へ追加しました。例：耳・口・五・两・请・暖・软・肯・窘、包・杯・茶・床・爱・饭。二・多・牛のように副次的な語義の注記で自動選定から外れる字も、採用する読みを個別に指定しています。自動選定の除外条件は維持し、未確認の候補は採用していません。`fá` は第2声を単独音で確認できるよう、例字「罚」を追加しています。

テストでは、すべての採用済み単独例字が詳細画面の選択処理で使えることに加え、主要音節に少なくとも一つ再生対象の例があることを確認します。第3声の全三声は今回採用した録音の対象一覧に従い、文脈例語だけがある組み合わせを自動追加しません。辞書上の候補をすべて採用することや、全音節の全声調を埋めることは条件にしていません。

## 音声について

聞き比べの15組には、Chen Wang 王琛による第1声の27音節の録音を収録しています。[audio-cmn](https://github.com/hugolpz/audio-cmn)のMP3を変更せず同梱し、ファイル内のピンイン・声調・話者・ライセンス情報を照合しています。個別・交互・順番の再生はすべてこの録音を使い、原速で再生します。例字データや端末の中国語TTSがなくても再生でき、録音を読み込めないときはエラーを表示して停止します。TTSでは代用しません。[録音の出典・ライセンス](public/audio/syllables/credits.html)と[取得情報・ハッシュ値](public/audio/syllables/manifest.json)を同梱しています。

「表記と声調」の軽声の4例（妈妈・爷爷・奶奶・爸爸）には、中国出身の話者による録音を収録しています。元の長さ・高さを保つため原速で再生し、TTSの音声・速度設定は適用しません。中国語の読み上げ音声がない端末でも再生できます。録音の取得・再生に失敗したときはエラーを表示し、TTSでは代用しません。[録音の出典・ライセンス](public/audio/neutral/credits.html)と[取得情報・ハッシュ値](public/audio/neutral/credits.json)を同梱しています。

音節詳細の第1・2・4声と全三声には、聞き比べと共通の単独音録音を使います。2026-10-21時点で再生対象だった1,162組に範囲を固定し、1,161組を収録しました。`yō` は「単独音の録音は未収録」と表示します。単独例字・例語は参考として残し、例字データを読み込めなくても録音を再生できます。録音の再生時はTTSの音声・速度設定を表示せず、録音の取得・再生に失敗してもTTSへ切り替えません。

単独音の管理ファイルは `public/audio/syllables/manifest.json` に統一しています。固定revision、元音源のキー、SHA-256、サイズ、長さ、話者、著作者、ライセンスを管理します。アプリのキー `ju4` と元音源の `jv4`、`ü` とファイル名の `v` は区別して保持します。`peng3` の元ファイルには音節・話者のID3タグがないため、その例外をこのファイルに明記し、取得元のバージョンを固定したうえで、配布元の情報とハッシュで確認しています。音声ファイルは変更せず利用します。

`scripts/build_recordings.py` から再生索引と出典ページを生成します。通常のビルドやテストでは音源をダウンロードしません。

```sh
python scripts/build_recordings.py --check          # 台帳・ファイル・生成結果をオフラインで照合
python scripts/build_recordings.py --fetch          # 採用済み音源のみ取得・生成（ffprobeが必要）
python scripts/build_recordings.py --check --audit  # 全件デコード・音量・長さ・重複の検査（ffmpegが必要）
```

自動検査では元のファイルとの一致や破損の有無などを確かめます。すべての録音を人が聞いて発音を確認したという意味ではありません。図とIPAも、音声を測定して作成したものではありません。現在対象外の声調を、配布元に録音が存在するという理由だけで採用しません。文脈例語だけがある第3声48組などの追加候補は別途確認します。

半三声・3声＋3声の7例には、The Shtooka Project の録音を収録しています。

| 発音形 | 録音で再生する例語 |
|---|---|
| 半三声 | 好吃 hǎochī・老师 lǎoshī・水平 shuǐpíng・准备 zhǔnbèi |
| 3声＋3声の変調 | 老板 lǎobǎn・水果 shuǐguǒ・准许 zhǔnxǔ |

「准许」はaudio-cmn、それ以外はWikimedia Commonsから取得しました。「老板」「准许」はYue TanによるCC BY-SA 3.0 US、ほかの5例はWei Gao, Vion NicolasによるCC BY 2.0 Franceです。配布元のMP3を変更せず、例語全体を元の速度で再生します。例語・読み・対象位置・発音形が一致した場合だけ録音を選び、読み込みや再生に失敗してもTTSへ切り替えません。[出典・ライセンス](public/audio/third-tone/credits.html)と[取得情報・ハッシュ値・確認範囲](public/audio/third-tone/credits.json)を同梱しています。「准许」は元のFLACの読み・著作権・ライセンス情報を確認し、波形を照合してMP3との対応も確認しました。

`lao3`・`shui3`・`zhun3` を検索すると、全三声・半三声・変調をすべて録音で確認できます。半三声では「老师」が第1声の前、「水平」が第2声の前、「准备」が第4声の前の例です。話者は録音によって異なるため、高さそのものではなく各音の中での変化に注目してください。「好友」は再配布条件まで確認できる音源が見つからなかったため、TTSを継続します。

音節詳細の軽声と、録音を収録した7例以外の半三声・3声＋3声では、Web Speech APIを使って例語全体を読み上げます。対象の文字とピンインに下線を引きます。単独音の録音を文脈内の発音の代わりには使いません。ピンイン・IPAをそのまま渡したり、pitchを変更して声調を偽装したりしません。TTSは表示した読み・発音形と異なる場合があります。

有効な音節にも、すべての声調の語があるとは限りません。現在の採用データに例字・例語がない `eng / ê / den / dia / tei / nou / nun / lo / zhei / chua / rua` などは、今回の単独録音の対象外です。未収録は「その発音の語が存在しない」との断定ではありません。

TTSを使う場合の音声一覧は起動時・一覧変更時・画面に戻ったとき・再生ボタンを押したときに再取得します。普通話の音声が一覧にない場合も、`lang: zh-CN` で端末に音声選択を任せます。端末側の選択・発音を保証するものではありません。

### Android・ChromeでTTSの例語の音声が出ない場合

1. 端末の「設定」で「テキスト読み上げ」を検索します。
2. 使用中の読み上げエンジンの設定で「音声データをインストール」を開き、「中国語（中国本土）」または「普通話」を追加します。
3. Chromeを開き直してページを再読み込みし、再生します。

項目名は機種・エンジンにより異なります。[Googleの設定手順](https://support.google.com/accessibility/android/answer/6006983?hl=ja)。アプリの「音声が出ないとき」からも確認できます。TTSを使う例語では、端末に中国語の音声が必要です。録音の再生には不要です。メディア音量・Bluetoothの出力先・通信接続も確認してください。表は音声なしでも動作します。オンライン音声には通信が必要です。

## 収録範囲とIPA方針

韻母の表示順は、[アイオワ大学の初級教材](https://pressbooks.uiowa.edu/zheng/back-matter/pinyin-chart-finals/)などで使う学習順を軸にしています。教材間で配列・収録範囲は異なり、収録する全分類に唯一の標準順があるという意味ではありません。基礎的な複合韻母は `ai / ei / ui / ao / ou / iu / ie / üe` の順、鼻韻母は `an / en / in / un / ün` と `ang / eng / ing / ong` の順を使い、追加の韻母はそれぞれの分類の後ろに補っています。単韻母には `ê`・`er` と舌先の2種類の i も含めます。韻母一覧では i の3種類を隣り合わせのカードにし、マトリクスでは1列にまとめます。40項目のうち「補足の音節」に分類するのは `yo`（分析上の韻母 `io`）です。分析用の韻母IDは変えず、表の見出しに `uei (ui)`・`iou (iu)`・`uen (un)` を併記します。綴りの系統（i系・u系・ü系など）による絞り込みも引き続き使えます。「i系」は [i] 系、舌先の i は「特殊韻母」に含まれます。絞り込み後もマトリクスの列見出しは i です。

学習用の明示的な音節リストを採用し、声母と韻母の直積は使いません。[香港中文大学の教材](https://www.ilc.cuhk.edu.hk/workshop/Chinese/Putonghua/PLW/ch3_content.html)などで用いられる伝統的な分類に合わせ、単韻母10・複合韻母13・鼻韻母16の39分類に、補足の `yo` を加えて40項目としています。マトリクスは i の3種類を統合した38列です。これらの数は言語学で唯一の分析を意味しません。分析用データでは、舌尖の `-i(z)` / `-i(zh)`、`er`、`ê`、`io` を引き続き区別します。

茶色は感動詞・口語の異読など、掲載範囲が資料によって異なる周辺的な音節です。児化の全組み合わせ、方言だけの綴り、音節主音の `m / n / ng / hm / hng` はマトリクスの対象外です。

「韻母一覧」の末尾には「鼻音が中心になる音節」の補足欄があります。呣・嗯・噷・哼の特殊な読みをピンイン・IPAで示し、母音を含む `hēng` との違いも説明します。この欄は上の40項目とは別枠で、録音は未収録です。「すべて」「特殊韻母」の絞り込みで表示し、韻母一覧のピンイン・漢字・IPA検索に対応しています。表記の参考は漢典の [呣](https://www.zdic.net/hans/呣)・[嗯](https://www.zdic.net/hans/嗯)・[噷](https://www.zdic.net/hant/噷)・[哼](https://www.zdic.net/hans/哼) です。

IPAは広い音声表記の一案に統一しています。`eng [əŋ]`、`ie [jɛ]`、`üe [ɥɛ]`、`r [ɻ]`、舌尖の `i [ɹ̩ / ɻ̩]` などを採用し、主要な異表記は注記します。唇音後の `o` は `[u̯o]〜[o]` 系など渡り音の扱いに分析・話者差があり、[ワシントン大学の音節表](https://courses.washington.edu/chin342/ipa/syllables.html)は `[uɔ]` 系を用います。本アプリでは広く `[wo]` と表記し、その選択を注記します。`ri` 全体は `[ɻ̩]` とまとめます。わたり音は `[j / w / ɥ]` で表記します。

マトリクスのIPAは声調なし、詳細では1〜4声の代表的な調形を付記し、第3声は選択した発音形に応じて切り替えます。軽声には固定の高さを与えず、母音の弱化などは説明にとどめます。機械的な連結では表せないすべての異音・変調を再現する音声学辞典ではありません。
